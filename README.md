# Creacamp : supports de la journée

Supports projetés lors du Creacamp « Veille, échanges et co-créations pédagogiques » (référents enseignement IA).

- `creacamp_quoi_de_neuf_ia.html` : « Quoi de neuf en IA ? », quatre axes (outils à surveiller, fonctions nouvelles, enjeux, divers). Informations contrôlées le 7 novembre 2026, sources indiquées sur chaque diapositive.
- `creacamp_fishbowl.html` : support du fishbowl (consigne, dispositif avec chrono par question, synthèse).
- `creacamp_prototypage.html` : support de la dernière partie (idées en 8 gestes, chrono, travail en équipes, partage).
- `logos/` : logos des outils cités et pictogrammes utilisés dans les supports.

Chaque support est un fichier HTML autonome : il s'ouvre par double clic dans un navigateur, sans connexion nécessaire.

Support réalisé par Angelo (AMlearn) avec l'aide de l'IA.

## Logos

Les logos des outils appartiennent à leurs propriétaires (Google, Anthropic, OpenAI, Mistral AI, Canva et les autres éditeurs). Ils figurent ici pour illustrer une présentation pédagogique et n'impliquent aucun partenariat ni aucune approbation.
